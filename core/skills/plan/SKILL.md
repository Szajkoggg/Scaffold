---
name: plan
description: Write a plan for larger work in docs/plans from the closest template (feature, bugfix, refactor, spike, performance, health-check), or continue an existing plan. Use when work spans sessions or needs approval up front.
---

Follow `docs/process/planning.md`. To write a plan: pick the template from `docs/process/templates/`, read enough
code to make the steps concrete, and show the plan for approval. To continue a plan: read it, then work through it
as the section "Working through a plan" says.
If the user says the plan should run unattended, also follow `docs/process/unattended.md`.
