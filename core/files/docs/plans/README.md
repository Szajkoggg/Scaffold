# Plans

**Summary:** One file per piece of work too large for a single chat request. The format and when a plan is needed:
`../process/planning.md`. Templates: `../process/templates/`.

- Active plans are here, named `YYYY-MM-DD-<slug>.md`.
- A finished or abandoned plan moves to `done/` with its outcome filled in; it is kept as the record of why the work
  was done the way it was.
