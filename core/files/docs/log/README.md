# Log

**Summary:** What was done and decided, and why, dated, one file per topic. Read a topic's entry list, then only the
entries you need; never a log end to end.

## Conventions

- **One file per topic** (`log/<topic>.md`), named for an area of the project, not a date.
- **Entries are appended** at the end and not rewritten later. Format:

  ```
  ## YYYY-MM-DD: <what, in a few words>
  What was done and why; what was decided and by whom; numbers where they exist. Links: plan, commits.
  ```

- **Short**: a few lines. The detail is in the commit, the plan or the design; the entry says where.
- **Growth**: a file past ~40 KB moves its older entries to `log/<topic>/<year>.md` and keeps a line pointing there.
