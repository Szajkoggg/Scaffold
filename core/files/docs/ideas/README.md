# Ideas

**Summary:** Ideas and the user's decisions on them, one file per topic. Nothing here is work in progress: a decided
idea becomes a plan when the user asks for one.

## Conventions

- **One file per topic**, kebab-case (`offline-mode.md`). A new aspect of a topic goes into its file.
- **A Summary first**: `**Summary:** …`, one to three sentences: the topic and what has been decided so far. Kept
  current whenever the file changes.
- **Sections**: `## Background` (optional: facts, with file and symbol references); `## Decided` with dated entries
  (`### YYYY-MM-DD`); `## Ideas (not decided)`; `## Open` (questions waiting for the user, "Nothing at the moment."
  when none).
- **Only the user's decisions go under Decided.** An agent's proposal stays under Ideas or Open until the user
  accepts it.
- **Facts stay checkable**: name the file, symbol or commit they come from. When something has been built since,
  say so with the commit instead of rewriting the decision.
